慧尖 LoRa 网关

一体化 MQTT Broker + mDNS 广播 + 网关集成

📋 使用流程

1

安装并启动插件

安装后点击「启动」，插件自动完成：mDNS 广播、Mosquitto Broker、网关集成安装、HA MQTT 集成配置

2

配置 LoRa 网关连接

在 LoRa 网关配置界面填写：Broker huijian.local，端口 1883，用户名 huijian，密码 huijian2022

3

重启 HA 并等待网关上报

重启 Home Assistant 让集成生效。LoRa 网关上电后会自动向 MQTT 上报，HA 会弹出「发现新设备」通知，点击添加即可

4

添加子设备（配对）

网关添加成功后，在设备页面找到「配对」按钮，按下后网关进入配对模式，子设备上报后自动添加到 HA

🔌 服务状态

Mosquitto Broker 运行中
mDNS 广播 运行中
网关集成 已安装
HA MQTT 集成 已配置
Ingress Web UI 运行中

📡 连接信息

MQTT 端口 1883
Broker 地址 huijian.local
用户名 huijian
密码 huijian2022
mDNS 主机名 huijian.local

💡 LoRa 网关 MQTT 配置

在 LoRa 网关的配置界面中填写以下信息：

Broker 地址: huijian.local（或 HA 的 IP 地址）
端口: 1883
用户名: huijian（可在插件配置中修改）
密码: huijian2022（可在插件配置中修改）

🔧 MQTT 主题协议

HA → 网关: gateway/{网关SN}/req（命令下发）
网关 → HA: gateway/rpt_rsp（状态上报）

⚠️ 注意事项

• 修改用户名/密码后需重启插件并更新 LoRa 网关配置
• 安装或更新集成后需重启 Home Assistant
• 网关添加后，在设备页面找到「配对」按钮添加子设备
• 如 mDNS 不可用，LoRa 网关可使用 HA 的 IP 地址
